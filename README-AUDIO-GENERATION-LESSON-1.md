# ملفات صوت مفردات الدرس الأول

الملفات المطلوبة لإنشاء التسجيلات هي:

- `data/lesson1/vocabulary.ts`: الكلمات والجمل والترجمات.
- `data/lesson1/practice.ts`: كلمات وأسئلة التمارين.

أنشئ تسجيلًا عربيًا واضحًا لكل كلمة، ولكل جملة مثال، ولكل كلمة منطوقة في أسئلة الاستماع والتمارين.

## أسماء الملفات المقترحة

```text
word-01.mp3 إلى word-22.mp3
sentence-01.mp3 إلى sentence-22.mp3
practice-word-01.mp3 ...
practice-sentence-01.mp3 ...
```

اقرأ النص العربي كما هو، مع التشكيل، ولا تنطق الترجمة الإنجليزية. أعد الملفات الصوتية في ZIP، مع جدول يطابق اسم كل ملف بالنص الذي نُطق.
